# AGENTS.md

This repository is a hot rolling path.

- Whenever you make a change, commit it and push it to `main` immediately.
- Do not create feature branches, pull requests, or worktrees unless the user explicitly asks for one.
- Keep the working tree clean; the user expects changes to be in the GitHub repository as soon as they are made.
- Never commit `.env`, `config.toml`, `data/`, or other local secrets. They are git-ignored.
